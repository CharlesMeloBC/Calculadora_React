# Calculadora em React

Uma calculadora simples construída com **React**. Este projeto permite realizar operações básicas de matemática como adição, subtração, multiplicação e divisão.

## Funcionalidades

- **Operações de soma (+), subtração (-), multiplicação (x) e divisão (/)**
- **Botão de igual (=) para calcular o resultado**
- **Botão de limpar (C) para resetar a tela**
- **Entrada de números e ponto decimal (.)**

## Como Rodar o Projeto

### Pré-requisitos

Antes de rodar o projeto, tenha certeza de que você tem o **Node.js** e o **npm** instalados na sua máquina.

- **Node.js**: [Baixe aqui](https://nodejs.org/)
- **npm**: O npm é instalado junto com o Node.js
